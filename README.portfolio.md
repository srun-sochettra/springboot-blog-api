# Spring Boot Blog API

Java 21 / Spring Boot 3.4.1 backend exploring authenticated blog workflows with PostgreSQL, MyBatis and Pinata uploads.

Highlights include owner checks for post/comment mutations, database token-version logout, response DTOs excluding password hashes, relational constraints and mocked service tests for selected scenarios.

These are source-backed implementation details, not claims of audited security, production deployment or passing integration tests. Upload cleanup and container configuration need review.

Read [README.md](README.md) and [local setup](README.onboarding.md). No runtime checks were executed during this refresh.
